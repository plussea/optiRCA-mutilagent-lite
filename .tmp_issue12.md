## What to build

Implement the **Evaluator** component that runs offline regression over archived dossiers or uploaded labeled batches, computes the PRD multi-objective metrics (`Top1_Acc`, `Top3_Recall`, `Critic_Recall`, `Critic_False_Reject`, `AvgLatency`), and emits structured error attribution text for failures.

## Acceptance criteria

- [ ] `POST /v1/evaluate` accepts either a list of `dossier_ids` or a labeled batch upload.
- [ ] Evaluator computes Top-1 accuracy, Top-3 recall, Critic recall, Critic false-reject rate, and average latency from decision traces.
- [ ] Per-case results include predicted root cause, ground truth, match status, and error attribution.
- [ ] `GET /v1/evaluate/{evaluation_id}` returns the full evaluation report.
- [ ] Error attribution is structured and points to one of `{judge, rank, critic, prompt, weights, cases}`.
- [ ] Tests cover metric computation for success, failure, degraded, and multi-root cases.
- [ ] Full test suite remains green.
