# Demo 样本集

本目录包含 10 个单根因光网络告警样本。每个编号子目录均仅包含三个输入/验收文件：

```text
demo/
  01/
    alarm.csv
    topology.json
    expected.json
  ...
  10/
    alarm.csv
    topology.json
    expected.json
```

## 样本清单

| 编号 | 故障场景 | 根因真值 |
|---|---|---|
| 01 | S01 光纤断纤 | `link:N1-N2` |
| 02 | S01 光纤断纤 | `link:N2-N4` |
| 03 | S01 光纤断纤 | `link:N1-N4` |
| 04 | S02 线路衰减过大 | `link:N1-N2` |
| 05 | S02 线路衰减过大 | `link:N3-N5` |
| 06 | S03 光放大器失效 | `dev:N3` |
| 07 | S03 光放大器失效 | `dev:N4` |
| 08 | S07 色散补偿异常 | `dev:N2` |
| 09 | S07 色散补偿异常 | `dev:N3` |
| 10 | S07 色散补偿异常 | `dev:N4` |

## 使用约定

- `alarm.csv` 的表头和“定位信息”格式与原始 Demo 一致；定位信息使用标准机框、槽位、板卡、端口及层级定位字符串。
- 每个拓扑恠好包含 `N1` 至 `N5` 五个节点，链路连接和设备类型可有变化。
- `expected.json` 只用于测试验收，不应作为诊断输入。
- 链路故障的真值为 `link:<链路ID>`；板卡或功能单元故障的真值为 `dev:<设备ID>`。
- 当前系统对链路型样本的规则基线较成熟，设备型样本用于暴露设备与相邻链路候选同分或误排的问题。
