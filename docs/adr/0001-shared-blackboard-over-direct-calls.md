# ADR-0001: 共享黑板（异构证据图）作为 Agent 间唯一通信方式

**状态**：已接受  
**日期**：2026-07-27  
**决策人**：[姓名]

## 背景

系统包含 7 个一级 Agent 与 1 个 Orchestrator。Agent 需要交换中间产物（事实表、证据图、传播链、Top-K 候选、复核结论等）。可选的协作模式有两种：

1. **直接调用**：Agent A 通过函数/HTTP/gRPC 直接调用 Agent B。
2. **共享黑板**：所有 Agent 读写同一份结构化数据（异构证据图），通过数据状态间接协作。

## 决策

采用 **共享黑板** 模式，以异构证据图为唯一协作媒介，**禁止 Agent 间直接调用**。

## 理由

- **可审计**：任何中间状态都留存在图中，便于复盘与调试。
- **可替换**：单个 Agent 可被 mock、升级或替换，不影响其他 Agent 接口。
- **可并行**：多个 Agent 可同时读取或写入不同子图，天然支持流水线。
- **解耦**：Agent 只依赖图 Schema，不依赖其他 Agent 的实现、部署位置或可用性。

## 后果

### 正面

- 每个 Agent 的输入输出更清晰，便于独立测试。
- Orchestrator 只需调度 Agent 执行顺序，不处理 Agent 间协议转换。
- 诊断案卷可直接从图快照中抽取，降低归档复杂度。

### 负面

- 图 Schema 成为全局契约，变更成本高。
- 需要引入图数据库（Neo4j/NebulaGraph）或内存图引擎，增加运维复杂度。
- Agent 必须遵守读写约定，错误写入可能导致其他 Agent 行为异常。
